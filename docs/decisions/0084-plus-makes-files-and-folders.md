# 0084 · ＋ makes a new file or a new folder

> Changes [0056](0056-new-files-at-once.md) and [0080](0080-tester-fixes.md) (＋ in the sidebar's
> header made a document at once) and [0054](0054-document-settings.md) (a new folder at the top
> level only from the space below the files).

The owner asked:

> "When hitting the plus button to create a new document, it should also be possible to create a
> new folder."

**＋ in the sidebar's header is a menu** (*New file or folder*): **New file** and **New folder…**,
the top level's own menu, the one a right-click on the space below the files has. It opens under
the button; a second click on ＋, Escape, or a click elsewhere closes it, and focus goes back to ＋.

- **New file** is as it was ([0056](0056-new-files-at-once.md)): an untitled document at the top
  level, open, with the cursor in its title. It is one click more than before.
- **New folder…** asks for its name (`new-folder`, at the top level) as a folder's own New folder
  does.

A folder's row keeps its two buttons, New file and New folder; the empty workspace's **New
document…** still makes a document at once.
