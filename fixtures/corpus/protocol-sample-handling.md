# Purpose {#purpose}

This protocol describes how soil cores are collected, transported,
stored and sub-sampled for DNA extraction. It replaces version 2.0,
which did not specify the maximum time between collection and freezing.

# Collection {#collection}

+---------------+---------------------------------+------------------+
| Step          | Action                          | Notes            |
+===============+=================================+==================+
| Site prep     | Clear surface litter from a     | Record litter    |
|               | 30 × 30 cm area.                | depth.           |
+---------------+---------------------------------+------------------+
| Coring        | Take five cores to 10 cm with   | Wipe the corer   |
|               | the sterilised corer, one at    | with ethanol     |
|               | each corner and one centrally.  | between sites.   |
+---------------+---------------------------------+------------------+
| Pooling       | Combine cores in a labelled     | Do not pool      |
|               | sterile bag and mix by hand     | across plots.    |
|               | for 30 s through the bag.       |                  |
+---------------+---------------------------------+------------------+
| Cooling       | Place bag in the cool box       | Start the clock  |
|               | immediately.                    | here.            |
+---------------+---------------------------------+------------------+

: Field collection steps {#tbl-collection}

All cores must reach the freezer within **six hours** of being placed
in the cool box.

# Storage conditions {#storage}

| Bulk soil, field   | 4 °C       | 6 h                             |
+--------------------+------------+---------------------------------+
| Bulk soil, lab     | −20 °C     | 2 weeks                         |
+--------------------+------------+---------------------------------+
| Sub-samples for    | −80 °C     | indefinite                      |
| DNA extraction     |            |                                 |
+--------------------+------------+---------------------------------+
| Extracted DNA      | −20 °C     | 6 months; then move to −80 °C   |
+--------------------+------------+---------------------------------+

# Sub-sampling {#subsampling}

Sub-sampling is done in the laminar flow cabinet in room B.214. The
schedule below gives the order of operations for a batch of
twenty-four samples; it assumes two people working together.

-------------------------------------------------------------------
Time      Task                          Responsible
--------- ----------------------------- -----------------------------
09:00     Remove batch from −20 °C,     Person A
          thaw on ice for 60 min.

10:00     Sieve each sample through     Person A sieves, person B
          a 2 mm mesh; discard          labels tubes and records
          stones and roots.             weights.

11:30     Weigh 0.25 g aliquots into    Person B
          bead tubes, three per
          sample.

12:30     Return aliquots to −80 °C;    Both
          return remaining bulk
          soil to −20 °C.
-------------------------------------------------------------------

: Sub-sampling timetable for one batch

Weights should be recorded to the nearest milligram. If an aliquot is
outside 0.24–0.26 g, discard it and weigh again.

# Labelling {#labelling}

Labels follow the pattern `SITE-PLOT-DATE-REP`, for example
`KV-03-20240206-B`. Use solvent-resistant labels; the ordinary ones
come off in the −80 °C freezer.

  Code   Site                Region
  ------ ------------------- --------------
  KV     Kivijärvi meadow    Central
  RA     Rautio pasture      North
  SL     Sääksjärvi forest   South-west

# Deviations {#deviations}

Any deviation from this protocol must be recorded in the deviation
log, with the date, sample IDs affected, what was done differently,
and why. Examples of deviations that have occurred in previous seasons:

- cool box left in a vehicle in direct sun (temperature logger showed
  14 °C after two hours);
- freezer alarm during a power cut, duration unknown;
- corer not sterilised between two plots.

Report deviations to the study coordinator the same day.
